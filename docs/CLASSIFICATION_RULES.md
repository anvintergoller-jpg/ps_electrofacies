# Правила классификации формы аномалий ПС

**Версия:** 1.0 (утверждено)
**Дата:** 2026-09-25
**Статус:** утверждено, используется для разработки

## 1. Назначение

Документ описывает правила классификации формы аномалии для каждого
интервала, выделенного на шаге сегментации.

Реализация — `src/domain/classify_form.py`.
Все числовые параметры — в `config/config.yaml`, секция `classification`.

## 2. Что классифицируем

Классификации подлежат **все интервалы `reservoir`** из таблицы
сегментации, у которых мощность ≥ 1 м в абсолютных отметках.

Интервалы `non_reservoir` (глина) не классифицируются — их форма не
несёт геологического смысла для типизации коллектора.

Микроинтервалы < 1 м **присоединяются к соседним** на шаге сегментации
и в классификацию не попадают.

## 3. Опорные точки

Для каждого интервала `reservoir` (≥ 1 м) вычисляются три средних
по **сглаженной** кривой SP_norm:

| Поле      | Смысл                                              |
|-----------|----------------------------------------------------|
| `sp_top`  | Среднее в верхних 15% мощности интервала           |
| `sp_mid`  | Среднее в центральных 15% мощности                 |
| `sp_bot`  | Среднее в нижних 15% мощности интервала            |

**Доли, а не фиксированные точки.** Параметр `edge_frac` в config,
стартово 0.15. Это масштабируется одинаково для интервалов любой
мощности — от 2 до 30 м.

**Сглаженная кривая.** Сглаживание выполняется тем же окном
(`smooth_window` = 5), что и при сегментации. Это убирает локальный
шум, но сохраняет форму.

**Минимум данных.** Если `n_points < 5` → тип `uncertain`,
reason = «мало точек». На практике этого не должно случаться, так
как минимальная мощность интервала 1 м = 10 точек при шаге 0.1 м.

## 4. Типы аномалий

| Тип                 | Геологический смысл                                       |
|---------------------|-----------------------------------------------------------|
| `bell`              | Колокол — регрессия, устье канала, конус выноса           |
| `funnel`            | Воронка — трансгрессия, бар, пляж                         |
| `cylinder`          | Цилиндр — однородный песчаник, массивное русло            |
| `symmetric`         | Симметричная (линза) — переходное тело                    |
| `trapezoid-top`     | Трапеция с плато у глинистой кровли                       |
| `trapezoid-bottom`  | Трапеция с плато у песчаной подошвы                       |
| `trapezoid-middle`  | Трапеция с плато в середине (линза или инверсия)          |
| `uncertain`         | Форма не определена                                        |

Всего — 8 категорий.

## 5. Правила классификации

Порядок проверок **важен**. Идём от специфичного к общему.

### 5.1. Обозначения и знаки

Пусть:
- `diff_top_bot = sp_top − sp_bot`
- `diff_top_mid = sp_top − sp_mid`
- `diff_bot_mid = sp_bot − sp_mid`

Шкала SP_norm:
- **Высокое значение** (близко к 1) = глина.
- **Низкое значение** (близко к 0) = песчаник.

Отсюда:
- **bell**: верх глинистый (высокий), низ песчаный (низкий) →
  `diff_top_bot > 0`.
- **funnel**: верх песчаный, низ глинистый → `diff_top_bot < 0`.

### 5.2. Пороги

| Параметр             | Значение | Смысл                                    |
|----------------------|----------|------------------------------------------|
| `cutoff`             | 0.6      | Граница коллектор/неколлектор (SP_norm)  |
| `threshold_diff`     | 0.2      | Порог разницы верх/низ для bell/funnel   |
| `plateau_threshold`  | 0.10     | Порог «плато» между опорами              |
| `slope_threshold`    | 0.20     | Порог «наклона» между опорами            |
| `skew_symmetric`     | 0.3      | Порог |skew| для symmetric                |
| `slope_ratio_min`    | 0.5      | Нижняя граница симметрии по наклону      |
| `slope_ratio_max`    | 2.0      | Верхняя граница симметрии по наклону     |
| `extremum_center_tol`| 0.15     | Допуск положения экстремума от центра    |

Все параметры — в `config.yaml`. Значения выше — стартовые.

### 5.3. Проверки в порядке

**Шаг 1. Мало данных.**
Если `n_points < 5`:
- Тип: `uncertain`, confidence: 0.0.
- Reason: `"мало точек ({n_points})"`.

**Шаг 2. Цилиндр (cylinder).**
Если:
- `|diff_top_bot| < threshold_diff` И
- `sp_top < cutoff` И `sp_mid < cutoff` И `sp_bot < cutoff`

То:
- Тип: `cylinder`.
- Confidence: `1.0 − |diff_top_bot| / threshold_diff`.
- Reason: `"плато на песчаном уровне"`.

**Шаг 3. Колокол (bell) и его варианты.**
Условие: `diff_top_bot > threshold_diff`.

Подслучай 3a. Плато сверху (`trapezoid-top`):
- Если `|diff_top_mid| < plateau_threshold`.
- Тип: `trapezoid-top`.
- Confidence: `min(1.0, diff_top_bot / threshold_diff − 0.5)`.

Подслучай 3b. Плато снизу (`bell` классический):
- Если `|diff_bot_mid| < plateau_threshold`.
- Тип: `bell`.
- Confidence: `min(1.0, diff_top_bot / threshold_diff − 0.5)`.

Подслучай 3c. Общий случай (без явного плато):
- Тип: `bell`.
- Confidence: `min(1.0, diff_top_bot / threshold_diff − 0.5)`.

**Шаг 4. Воронка (funnel) и её варианты.**
Условие: `diff_top_bot < −threshold_diff`.

Подслучай 4a. Плато сверху (`trapezoid-bottom`):
- Если `|diff_top_mid| < plateau_threshold`.
- Тип: `trapezoid-bottom`.
- Confidence: `min(1.0, |diff_top_bot| / threshold_diff − 0.5)`.

Подслучай 4b. Плато снизу (`funnel` классический):
- Если `|diff_bot_mid| < plateau_threshold`.
- Тип: `funnel`.
- Confidence: `min(1.0, |diff_top_bot| / threshold_diff − 0.5)`.

Подслучай 4c. Общий случай:
- Тип: `funnel`.
- Confidence: `min(1.0, |diff_top_bot| / threshold_diff − 0.5)`.

**Шаг 5. Трапеция с плато в середине.**
Условие:
- `|diff_top_mid| > slope_threshold` И
- `|diff_bot_mid| > slope_threshold`

То:
- Тип: `trapezoid-middle`.
- Confidence: `min(1.0, (|diff_top_mid| + |diff_bot_mid|)
  / (2 * slope_threshold) − 0.5)`.
- Reason: `"плато в середине, наклоны с обеих сторон"`.

**Шаг 6. Симметричная (symmetric).**
Проверяются три метрики:

1. `|skewness| < skew_symmetric`
2. `slope_ratio_min ≤ |slope_top / slope_bottom| ≤ slope_ratio_max`
3. `|extremum_position − 0.5| < extremum_center_tol`

Если выполнены **2 из 3** или больше → `symmetric`.

Confidence:
- 2 из 3 — 0.6
- 3 из 3 — 0.85

Reason: `"симметричная линия ({n_metrics} из 3 метрик)"`.

**Шаг 7. Иначе — uncertain.**
- Тип: `uncertain`, confidence: 0.3.
- Reason: `"ни одно правило не сработало"`.

## 6. Литологический профиль пласта-контейнера

Для каждого пласта-контейнера считаем **доли точек** в каждом
из пяти классов αПС (или эквивалентно по SP_norm):

| Поле               | Класс αПС    | Диапазон SP_norm |
|--------------------|--------------|------------------|
| `pct_shale`        | Глина        | 0.8 – 1.0        |
| `pct_silty_shale`  | Алевролит глинистый | 0.6 – 0.8 |
| `pct_silt`         | Алевролиты и песчаники | 0.4 – 0.6 |
| `pct_sand_m`       | Песчаник среднезернистый | 0.2 – 0.4 |
| `pct_sand_c`       | Песчаник крупнозернистый | 0.0 – 0.2 |

Сумма = 1.0. Считается по **сглаженной** SP_norm, чтобы убрать
пиксельный шум.

**Зачем это нужно.** NTG — грубая характеристика (доля песчаника).
Литологический профиль — детальная: он различает, например,
тонкослоистый разрез с высоким NTG от массивного песчаника с тем же
NTG. Это критично для характеристики разреза.

## 7. Положение интервала в пласте-контейнере

| Поле                    | Смысл                                          |
|-------------------------|------------------------------------------------|
| `centroid_tvdss`        | Центр масс интервала в АО                      |
| `centroid_relative`     | 0..1: положение центроида в контейнере         |
| `position_in_container` | top / middle / bottom                          |

Границы:
- `top`:    `centroid_relative < 0.33`
- `middle`: `0.33 ≤ centroid_relative ≤ 0.67`
- `bottom`: `centroid_relative > 0.67`

Центроид, а не медиана — устойчивее для интервалов с одним большим
однородным участком.

## 8. Категория размера интервала

Сравнение между интервалами одной скважины (позже — между скважинами).

| Категория | Условие                                         |
|-----------|-------------------------------------------------|
| `small`   | толщина < 33-го перцентиля среди интервалов     |
| `medium`  | между 33-м и 67-м перцентилями                  |
| `large`   | толщина > 67-го перцентиля                      |
| `unknown` | меньше 3 интервалов в выборке                   |

Применяется к `thickness_tvdss` интервала.

## 9. Итоговая таблица классификации

Одна строка на каждый интервал reservoir. Колонки:

**Идентификация:**
- `layer_name`, `interval_index`

**Положение и размер:**
- `top_tvdss`, `bottom_tvdss`, `thickness_tvdss`

**Опоры и производные:**
- `sp_top`, `sp_mid`, `sp_bot`
- `diff_top_bot`, `diff_top_mid`, `diff_bot_mid`

**Тип:**
- `anomaly_type`, `confidence`, `reason`

**Форма (сырые признаки):**
- `skewness`, `slope_top`, `slope_bottom`, `slope_ratio`
- `extremum_position`

**Положение в контейнере:**
- `centroid_relative`, `position_in_container`

**Размер:**
- `size_class` — заполняется на шаге E

**Ссылка на контейнер:**
- `container_thickness_tvdss` — мощность родительского пласта
- `container_ntg` — NTG пласта (доля резервуара ≥1 м)

## 10. Литологический профиль — в отдельной таблице

Так как литологический профиль считается **на пласт-контейнер**, а не
на интервал, храним его в таблице `features.csv` (уровень A).
Добавляются колонки: `pct_shale`, `pct_silty_shale`, `pct_silt`,
`pct_sand_m`, `pct_sand_c`.

## 11. Оговорки и правила изменений

1. **Все пороги в config.** Если геолог считает, что для его района
   `threshold_diff` должен быть 0.3, а не 0.2 — меняет одну строку
   в `config.yaml` и перезапускает пайплайн. Код не правится.

2. **Версионирование правил.** Если правила меняются — обновляем
   версию этого документа. Результаты классификации содержат
   `rules_version` — чтобы можно было сопоставить, какая версия
   правил использовалась.

3. **Классификация формы ≠ геологический диагноз.**
   `bell` — это форма кривой ПС. «Устье канала» — геологическая
   интерпретация, требующая комплекса методов. Мы делаем первый шаг,
   не делаем второй.

4. **Пока без ГК.** Классификация — только по SP_norm. ГК_norm
   считаем и сохраняем для будущего. Включение в правила — отдельный
   шаг (мультиметодность).

5. **Без фациальных моделей из учебника.** Барьерные острова, дельты,
   устьевые бары — это следующий уровень, требующий пространственных
   данных по нескольким скважинам и карт.

6. **Одна скважина — не выборка.** Категория `size_class` пока
   считается внутри одной скважины. Настоящая сила появится на
   10+ скважинах, когда распределение станет репрезентативным.
