# Состояние проекта ps_electrofacies

**Дата снимка:** 2026-09-29
**Текущий шаг:** H — сопоставление пластов между скважинами

## 1. Что это за проект

Разработка программы для типизации кривых ПС методом электрофациального
анализа. Пилот расширен до 5 скважин, в перспективе — обработка выборки
(до 1000 скважин) с выходом на типизацию пластов и картирование.

**Конечная цель:** для каждого пласта (БС9, БС10-1, …) в каждой
скважине получить одну строку со всеми характеристиками и уметь
сопоставлять одноимённые пласты между скважинами (см. ADR-003).

**Пользователь:** геолог-петрофизик, новичок в программировании, учится
«вайбкодингу с умом». Нужны подробные комментарии в коде и методике,
сначала документ — потом код.

**Стек:** Python 3.14, VS Code, Git/GitHub. Библиотеки: numpy, pandas,
matplotlib, lasio, openpyxl, pyyaml.

## 3. Ключевые методические решения

**Глубины и мощности:**
- Мощности — по TVDSS (абсолютные отметки), не по MD.
- Разметка точек пласта — по MD.
- Ось Y на графике — TVDSS.

**Нормализация:**
- SP_norm и GK_norm в [0, 1]: 0 = песок, 1 = глина.
- Перцентили 5 и 95 для опорных линий.

**Сегментация:**
- Порог коллектора SP_norm < 0.6 (αПС > 0.4 по Муромцеву).
- Сглаживание SP_norm: окно 5 точек (0.5 м).
- Микроинтервалы < 1 м присоединяются к соседним.

**Классификация формы (v2.0, ADR-001):**
- 6 типов: bell, funnel, cylinder, trapezoid-middle, symmetric,
  uncertain.
- Опоры — средние по 15% мощности интервала.
- Доработка критериев отложена до шага H (ADR-002).

**Размер и положение (шаг E):**
- Размер — доля мощности интервала в мощности контейнера
  (small < 0.33, medium 0.33–0.67, large > 0.67).
- Положение — по относительному положению центроида в контейнере
  (top / middle / bottom).

**Сводная типизация (шаг F, ADR-004):**
- Доминирующая характеристика — по мощности; при близости
  (< 10%) — по confidence.
- Формат: `container_type`, `container_summary`,
  `container_intervals_json`.
- NTG = 0 → `no-sand`.

**Единица анализа (ADR-003):**
- Пласт-контейнер, а не разрез скважины.

**Батч-обработка (ADR-005):**
- Список скважин: `wells: "auto"` или явный список.
- Пути через шаблоны `{well}`.
- Выход: `data/processed/<well_name>/` + сводка
  `summary_all_wells_<ts>.csv` + общий лог.

## 6. Ограничения и известные особенности

- **Классификация формы не идеальна.** Часть интервалов отнесена
  к формам, не совпадающим с ручной интерпретацией геолога
  (ADR-002).
- **Не все интервалы получают эталон на планшете.** Для типа
  `uncertain` линии не рисуются (по решению от 2026-09-28).
- **Категория `large` может не встречаться** при текущих порогах
  размера — коллекторы обычно занимают малую долю мощности пласта.
- **5 скважин — не выборка.** Все категории пока отражают одну
  локальную точку, но уже позволяют сопоставлять пласты.

## 7. Дорожка дальше

- **Шаг H** (текущий): сопоставление пластов между скважинами.
  Матрица «скважина × пласт», описательные сводки по типам.
  Кластеризация — отложена до накопления 10+ скважин на пласт.
- **Возврат к ADR-002** — доработка критериев классификации
  формы — после накопления ≥ 5 скважин с ручной разметкой
  (у нас уже 5 скважин, но разметки пока нет).
- **Шаг I** (перспектива): кластеры пластов, карты электрофаций.
