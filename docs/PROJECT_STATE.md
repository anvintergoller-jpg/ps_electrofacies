# Состояние проекта ps_electrofacies

**Дата снимка:** 2026-09-26
**Текущий шаг:** F — сводная типизация пласта

## 1. Что это за проект

Разработка программы для типизации кривых ПС методом электрофациального
анализа. Пилот на одной скважине, в перспективе — обработка выборки
(до 1000 скважин) с выходом на типизацию разреза и картирование.

**Пользователь:** геолог-петрофизик, новичок в программировании, учится
«вайбкодингу с умом». Нужны подробные комментарии в коде и методике,
сначала документ — потом код.

**Стек:** Python 3.14, VS Code, Git/GitHub. Библиотеки: numpy, pandas,
matplotlib, lasio, openpyxl, pyyaml.

## 2. Данные

Одна пилотная скважина `227_2263`:
- `data/raw/las/227_2263.las` — LAS каротаж, кривые SP и GK, шаг 0.1 м,
  NULL = -999.25. SP покрывает только интервал 2468–2808 м.
- `data/raw/deviation/227_2263.dev` — инклинометрия Petrel (текстовый
  формат, столбцы MD X Y Z TVD DX DY AZIM_TN INCL DLS AZIM_GN),

- `data/raw/markers/welltops_227_2263.xlsx` — отбивки (WellTops),
  столбцы: Well identifier, Surface (имя маркера), MD, PVD auto (TVDSS).
  7 маркеров: БС9_TOP_S, БС10-1_TOP_S, БС10-2_TOP_S, БС11-0_TOP_S,
  БС11-1_TOP_S, БС11-2_TOP_S, БС12_TOP_S.

**Важно:** последний пласт (БС12) — до конца данных .dev (2850.65 м MD).
Подошву геолог не ставит, мы доопределяем автоматически.

## 3. Ключевые методические решения

- **Мощности — по TVDSS (абсолютные отметки)**, не по MD. TVDSS
  в Petrel-стиле: отрицательные значения вниз (KB − TVD).
- **Разметка точек пласта — по MD.** Пласт = (depth_md >= top_md) &
  (depth_md < bottom_md).
- **График — ось Y = TVDSS.**
- **Нормализация** SP_norm и GK_norm к диапазону [0, 1]:
  0 = чистый песок, 1 = чистая глина. Считается только внутри
  рабочего интервала (от первой кровли до конца .dev).
- **Единый порог коллектора:** SP_norm < 0.6 (αПС > 0.4,
  по Муромцеву — «алевролиты и песчаники»).
- **Сглаживание** для сегментации и классификации — окно 5 точек (0.5 м).
- **Микроинтервалы < 1 м** присоединяются к соседним.
- **Классификация формы** по трём опорам: sp_top (верхние 15%),
  sp_mid (центральные 15%), sp_bot (нижние 15%).
- **6 типов аномалий (версия правил 2.0):** bell, funnel, cylinder,
  trapezoid-middle, symmetric, uncertain (см. ADR-001).
- **Размер интервала** — по доле мощности интервала в мощности
  родительского контейнера (small / medium / large). Пороги
  фиксированные (0.33 / 0.67), не перцентили выборки (см. ADR-002
  и запись про шаг E).
- **Положение интервала** — по относительному положению центроида
  в контейнере (top / middle / bottom, пороги 0.33 / 0.67).
