## Принципы работы

- Сначала методика (документ), потом код.
- Все параметры — в `config/config.yaml`, не в коде.
- Один параметр — одно место в config.
- Максимум комментариев в коде (проект учится с нуля).
- Не менять старое без причины.
- Каждая значимая итерация — commit + push в GitHub.
- Данные — только локально, в GitHub не попадают.
