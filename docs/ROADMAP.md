## Текущий шаг

**Шаг D.3. Классификатор формы.**

Написать `src/domain/classify_form.py` по правилам из
`docs/CLASSIFICATION_RULES.md`.

Типы аномалий:

- `bell` — колокол (регрессия, устье канала)
- `funnel` — воронка (трансгрессия, бар)
- `cylinder` — цилиндр (однородный песчаник)
- `trapezoid-top` — трапеция с плато у глинистой кровли
- `trapezoid-bottom` — трапеция с плато у песчаной подошвы
- `trapezoid-middle` — трапеция с плато в середине
- `symmetric` — симметричная линия (линза)
- `uncertain` — форма не определена

## Долгосрочные идеи

- Интеграция ГК в правила классификации (мультиметодность).
- Учёт фациальных моделей (Ежова, Муромцев) — расширение
  базовых типов формы.
- Машинное обучение — после накопления 20+ скважин с ручной
  разметкой.
- Карты электрофаций по пластам.
- Веб-интерфейс (Streamlit) для коллег-геологов.
- Пакетная обработка сотен скважин.

## Принципы работы

- Сначала методика (документ), потом код.
- Все параметры — в `config/config.yaml`, не в коде.
- Максимум комментариев в коде (проект учится с нуля).
- Не менять старое без причины.
- Каждая значимая итерация — commit + push в GitHub.
- Данные — только локально, в GitHub не попадают.
