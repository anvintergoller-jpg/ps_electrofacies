## Текущий шаг

**Шаг H. Сопоставление пластов между скважинами.**

Сформировать матрицу «скважина × пласт» на основе
`summary_all_wells.csv`. На первых порах — без кластеризации,
только описательные сводки:

- таблица `container_type` по пластам × скважинам;
- счётчики по каждому пласту: сколько раз встречается каждый тип;
- список «нетипичных» пластов (тип встречается один раз).

Кластеризация — после накопления 10–20 скважин на пласт
(статистика на 5 скважинах даст неустойчивый результат).

См. `docs/DECISIONS_LOG.md`, ADR-005.

## Долгосрочные идеи

- Интеграция ГК в правила классификации (мультиметодность).
- Учёт фациальных моделей (Ежова, Муромцев) — расширение
  базовых типов формы.
- Машинное обучение — после накопления 20+ скважин с ручной
  разметкой.
- Карты электрофаций по пластам.
- Веб-интерфейс (Streamlit) для коллег-геологов.
- Пакетная обработка сотен скважин.
