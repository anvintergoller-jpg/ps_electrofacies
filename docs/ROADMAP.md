## Текущий шаг

**Шаг F. Сводная типизация пласта.**

Собрать всё, что уже посчитано, в одну характеристику пласта:

- количество коллекторных интервалов,
- доминирующая форма,
- доминирующий размер,
- доминирующее положение,
- NTG пласта (доля коллектора в мощности пласта, в АО),
- тип пласта в виде короткой метки:
  - `single-bell-medium-top` — один колокол в кровле,
  - `multi-cylinder-middle` — несколько цилиндров в середине,
  - `no-sand` — глинистый пласт без коллекторов.

См. `docs/FEATURES.md`, §6.

## Текущий шаг

**Шаг F. Сводная типизация пласта.**

Собрать все признаки по каждому пласту-контейнеру в одну строку:

- `thickness_tvdss` — мощность пласта;
- `thickness_reservoir_tvdss` — суммарная мощность коллекторов;
- `ntg_tvdss` — доля коллектора в мощности пласта;
- `n_reservoir` — количество коллекторных интервалов;
- `dominant_form` / `dominant_size` / `dominant_position` —
  доминирующие характеристики (по мощности, при близости ≤10% —
  по confidence);
- `container_type` — короткая метка пласта;
- `container_summary` — текстовое описание (человеку);
- `container_intervals_json` — структурированный список
  интервалов (машине).

Всё хранится в `features.csv` (одна строка на пласт).

См. `docs/FEATURES.md`, §6.

## Долгосрочные идеи

- Интеграция ГК в правила классификации (мультиметодность).
- Учёт фациальных моделей (Ежова, Муромцев) — расширение
  базовых типов формы.
- Машинное обучение — после накопления 20+ скважин с ручной
  разметкой.
- Карты электрофаций по пластам.
- Веб-интерфейс (Streamlit) для коллег-геологов.
- Пакетная обработка сотен скважин.
