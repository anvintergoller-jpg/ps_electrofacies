# Признаки для типизации пластов

**Версия:** 0.3
**Дата:** 2026-09-30
**Статус:** актуально (после ревизии H.5)

## 1. Назначение документа

Этот документ фиксирует **какие признаки** мы считаем для каждого
пласта и каждого коллекторного интервала, и что каждый признак
означает.

Код (`src/domain/features.py`, `src/domain/size_class.py`,
`src/domain/container_type.py`) реализует то, что написано здесь.
Если что-то меняется в методике — сначала правится этот документ,
потом код.

См. также:
- `docs/CLASSIFICATION_RULES.md` — правила классификации формы.
- `docs/DECISIONS_LOG.md` — журнал решений (ADR).
- `docs/ARCHITECTURE.md` — карта модулей и поток данных.

## 2. Ключевые понятия

### 2.1. Пласт-контейнер (container)

Интервал между двумя соседними кровлями (по отбивкам).

Пример для скважины 227_2263:
БС9_TOP_S = 2615.15 м MD
БС10-1_TOP_S = 2653.20 м MD ← конец БС9 и начало БС10-1


Пласт БС9 = [2615.15, 2653.20] м MD, мощность 38.05 м.
Последний пласт (например, БС12) — до конца данных в `.dev`.

Пласты задаются **геологом** через отбивки. Мы не оспариваем их
границы и не сдвигаем.

**Единицы мощности.** По умолчанию мощность пласта и любого
интервала считается **по абсолютным отметкам (TVDSS)**. Это
инвариант к углу наклона ствола и позволяет корректно сопоставлять
пласты между скважинами.

Обозначения:
- `thickness_tvdss` — **главная метрика мощности**, м;
- `thickness_md` — справочная, для контроля и отображения.

### 2.2. Коллекторный интервал (reservoir interval)

Непрерывный интервал внутри пласта-контейнера, где кривая `aSP`
указывает на породы-коллекторы: **`aSP > 0.4`**.

Один пласт может содержать:
- 0 коллекторных интервалов (глинистый пласт);
- 1 коллекторный интервал (одиночный песчаник);
- 2 и более (переслаивание).

### 2.3. Микроинтервал

Коллекторный интервал мощностью < 1 м. В расчёт NTG и в типизацию
не идёт, но присоединяется к соседям на этапе сегментации.

### 2.4. aSP (alpha-PS, приведённый ПС)

Классическая безразмерная величина:
aSP = (shale_value − SP) / (shale_value − sand_value)

где `shale_value` и `sand_value` — опорные значения, полученные
как **перцентили 98 и 2** (соответственно) распределения SP
внутри рабочего интервала скважины.

Шкала aSP: **0 = глина, 1 = чистый песчаник.**

Классификация по Муромцеву, 5 равных отрезков:

| aSP        | Литология                        |
|------------|----------------------------------|
| 0.0 – 0.2  | глина                            |
| 0.2 – 0.4  | алевролит глинистый              |
| 0.4 – 0.6  | алевролиты и песчаники           |
| 0.6 – 0.8  | песчаник среднезернистый         |
| 0.8 – 1.0  | песчаник крупнозернистый         |

Граница «коллектор / не коллектор»: **aSP = 0.4**.

Оговорка: термины «среднезернистый», «крупнозернистый» — условные,
это интерпретация по форме кривой, а не прямое измерение зерна.

**Отличие от SP_norm (историческое).** До 30.09 использовалась
шкала SP_norm (0 = песок, 1 = глина), эквивалентная `1 − aSP`.
Переход на aSP — см. ADR-006.

## 3. Уровни признаков

- **A. Пласт-контейнер** — одна строка на пласт.
- **B. Коллекторный интервал** — одна строка на интервал
  (может быть несколько на один контейнер).
- **C. Сводная типизация** — итоговая характеристика пласта:
  NTG, доминирующий тип, container_type.

## 4. Признаки пласта-контейнера (уровень A)

| Признак                  | Тип   | Что означает                                                |
|--------------------------|-------|-------------------------------------------------------------|
| `layer_name`             | str   | Имя пласта (по отбивке кровли)                              |
| `top_md`, `bottom_md`    | float | Кровля / подошва по стволу, м                               |
| `top_tvdss`              | float | Кровля в абсолютных отметках, м                             |
| `bottom_tvdss`           | float | Подошва в абсолютных отметках, м                            |
| **`thickness_tvdss`** ⭐  | float | **Мощность по абсолютным отметкам, м** — главная метрика    |
| `thickness_md`           | float | Мощность по стволу, м — справочно                           |
| `n_points`               | int   | Всего точек каротажа в пласте                               |
| `n_sp_valid`             | int   | Точек с валидным aSP                                        |
| `sp_coverage`            | float | Доля валидных точек, 0..1                                   |

**Смысл `thickness_tvdss`.** Для наклонных скважин мощность по стволу
и по абсолютным отметкам сильно различаются. В пилотной скважине
смещение MD − TVDSS достигает 138 м, поэтому это критично для
корректного сопоставления пластов между скважинами.

## 5. Признаки коллекторного интервала (уровень B)

Считаем для **каждого** коллекторного интервала (`aSP > 0.4` после
сглаживания и фильтрации). Интервалы длиной < 1 м не считаем.

### 5.1. Положение в скважине

| Признак                | Тип   | Что означает                                 |
|------------------------|-------|----------------------------------------------|
| `layer_name`           | str   | Пласт-контейнер, к которому относится        |
| `interval_index`       | int   | Номер интервала внутри пласта (1, 2, 3...)   |
| `top_md`, `bottom_md`  | float | Кровля / подошва интервала в MD, м           |
| `top_tvdss`            | float | То же в абсолютных отметках, м               |
| `bottom_tvdss`         | float | То же                                        |
| **`thickness_tvdss`** ⭐ | float | **Мощность интервала по абсолютным отметкам** |
| `thickness_md`         | float | По стволу, справочно                         |

**Расчёт `top_tvdss`, `bottom_tvdss`:** линейная интерполяция
по таблице инклинометрии (`.dev`), функция `md_to_tvd`,
применённая к `top_md` и `bottom_md`.

### 5.2. Форма аномалии

Подробные правила — в `docs/CLASSIFICATION_RULES.md`.

| Признак            | Тип     | Что означает                                  |
|--------------------|---------|-----------------------------------------------|
| `form_type`        | str     | bell / funnel / cylinder / trapezoid-middle / symmetric / v-shape / uncertain |
| `confidence`       | float   | 0..1 — уверенность классификации              |
| `reason`           | str     | Короткое объяснение для геолога               |
| `rules_version`    | str     | Версия правил (сейчас 2.0)                    |
| `sp_top`, `sp_mid`, `sp_bot` | float | Опорные точки (в шкале aSP)         |
| `diff_top_bot`, `diff_top_mid`, `diff_bot_mid` | float | Разности опор |
| `frac_core`        | float   | Доля точек в ядре вокруг `sp_mid`             |

### 5.3. Размер интервала

Размер — по **доле мощности интервала в мощности родительского
пласта-контейнера**:
relative = thickness_interval_tvdss / thickness_container_tvdss


| Категория | Условие                                    |
|-----------|--------------------------------------------|
| `small`   | `relative < 0.33`                          |
| `medium`  | `0.33 ≤ relative ≤ 0.67`                   |
| `large`   | `relative > 0.67`                          |
| `unknown` | Контейнер не найден в layers (нет границ)  |
| `n/a`     | Для `non_reservoir`                        |

Пороги **фиксированные** (не перцентили выборки). Причина — размер
должен быть сопоставим между скважинами для одного и того же
пласта (см. ADR-002). Пороги в `config.yaml`,
секция `size_classification`.

### 5.4. Положение в контейнере

| Признак                 | Тип     | Что означает                                  |
|-------------------------|---------|-----------------------------------------------|
| `centroid_tvdss`        | float   | Центр масс интервала в абсолютных отметках    |
| `centroid_relative`     | float   | 0..1: положение центроида внутри контейнера   |
| `position_in_container` | str     | top / middle / bottom                         |

**Расчёт `centroid_tvdss`:** среднее TVDSS всех точек интервала
(не середина по границам — устойчивее для неравномерных
интервалов).

**Расчёт `centroid_relative`:**
centroid_relative = (top_tvdss_container − centroid_tvdss) /
(top_tvdss_container − bottom_tvdss_container)


**Категория `position_in_container`:**
- `top`:    `centroid_relative < 0.33`
- `middle`: `0.33 ≤ centroid_relative ≤ 0.67`
- `bottom`: `centroid_relative > 0.67`

Пороги в `config.yaml`, секция `size_classification`.

## 6. Сводные признаки пласта (уровень C)

Одна строка на пласт. Собирает результаты уровней A и B.

### 6.1. Формируемые колонки

**Мощности и NTG:**

| Признак | Что означает |
|---|---|
| `thickness_tvdss` | мощность пласта (из A) |
| `thickness_reservoir_tvdss` | суммарная мощность коллекторов ≥1 м |
| `ntg_tvdss` | `thickness_reservoir_tvdss / thickness_tvdss` |
| `n_reservoir` | количество коллекторных интервалов |

**Доминирующие характеристики:**

| Признак | Что означает |
|---|---|
| `dominant_form` | доминирующая форма (bell / funnel / …) |
| `dominant_size` | доминирующий размер |
| `dominant_position` | доминирующее положение |
| `mean_confidence` | средняя confidence по всем интервалам |

**Итоговая метка:**

| Признак | Что означает |
|---|---|
| `container_type` | короткая метка `{single/multi/no-sand}-{form}-{size}-{position}` |
| `container_summary` | текстовое описание (человеку) |
| `container_intervals_json` | JSON-массив интервалов (машине) |

### 6.2. Доминирующая характеристика

Основной критерий — **суммарная мощность** интервалов с этим
значением. Тай-брейк при близости (< 10% от общей мощности
резервуаров пласта) — по `mean_confidence`.

Порог близости — `container_type.dominance_margin` в config.

### 6.3. Формат `container_type`
{количество}-{форма}-{размер}-{положение}


- **Количество:** `single` (1 интервал) / `multi` (2+) / `no-sand`
  (NTG = 0, остальные части метки опускаются).
- **Форма:** bell / funnel / cylinder / trapezoid-middle / symmetric /
  v-shape / uncertain.
- **Размер:** small / medium / large.
- **Положение:** top / middle / bottom.

Примеры: `single-bell-medium-top`, `multi-cylinder-small-middle`,
`no-sand`.

### 6.4. Литологический профиль (из уровня A)

5 долей αПС: `pct_shale`, `pct_silty_shale`, `pct_silt`,
`pct_sand_m`, `pct_sand_c`. Сумма = 1.0. Считается по сглаженной
aSP. Детали — в §7.

### 6.5. Формат `container_intervals_json`

JSON-массив, один объект на интервал:
```json
[
  {"form": "bell", "size": "medium", "position": "top",
   "thickness": 6.66, "confidence": 1.00,
   "top_tvdss": -2364.13, "bottom_tvdss": -2370.80}
]

. Литологический профиль пласта-контейнера
Для каждого пласта считаем доли точек в каждом из пяти
классов αПС (шкала aSP, 0 = глина, 1 = песок):

Поле	Класс αПС	Диапазон aSP
pct_shale	Глина	0.0 – 0.2
pct_silty_shale	Алевролит глинистый	0.2 – 0.4
pct_silt	Алевролиты и песчаники	0.4 – 0.6
pct_sand_m	Песчаник среднезерн.	0.6 – 0.8
pct_sand_c	Песчаник крупнозерн.	0.8 – 1.0
Сумма = 1.0. Считается по сглаженной aSP
(окно preprocessing.smooth_window).

Зачем это нужно. NTG — грубая характеристика (доля песчаника).
Литологический профиль — детальная: различает, например,
тонкослоистый разрез с высоким NTG от массивного песчаника с тем же
NTG. Это критично для характеристики разреза.

8. Категории размера и положения (сводно)
Применяются к каждому коллекторному интервалу (уровень B).

Признак	Категории
size_class	small / medium / large / unknown / n/a
position_in_container	top / middle / bottom
Пороги — фиксированные, в config.yaml (секция
size_classification). См. §5.3 и §5.4.

9. Отображение и разметка
9.1. Ось Y на графике — TVDSS
Соответствует практике построения корреляционных схем: все скважины
отображаются в единой системе глубин.

Практически:

Каждая точка каротажа переводится в (SP, depth_tvdss) или
(aSP, depth_tvdss).

Кровли пластов рисуются горизонтальными линиями на уровне
top_tvdss.

Фильтрация видимого интервала — по top_tvdss верхней кровли
и bottom_tvdss нижней.

9.2. Разметка точек пласта — по MD
Точки каротажа приходят с MD-шагом. Попадание в пласт определяется
по MD:

text
(depth_md >= top_md) & (depth_md < bottom_md)
В таблице dataset.csv хранятся обе координаты:

depth_md — для сопоставления с LAS и отбивками;

depth_tvdss — для отображения и сопоставления со скважинами.

10. Выгрузка для Petrel
Отдельный скрипт src/export_to_petrel.py. Два продукта:

LAS с FACIES — по одной кривой на скважину.
Кривые: DEPT, aSP, FACIES (числовой код формы, см.
petrel_legends.txt). Диапазон — весь LAS, вне пластов NULL.

Points with Attributes — по одному .txt файлу на пласт.
XYZ — координаты кровли из welltops. Атрибуты: Well, Layer,
ContainerCode, Container, DominantFormCode. Имена пластов
транслитерируются (Petrel не читает кириллицу).

Легенды — в data/processed/petrel/petrel_legends.txt.

11. Оговорки и открытые вопросы
Порог aSP = 0.4 — по Муромцеву. Регионально-зависимая
величина. Меняется в config.yaml.

Сглаживание — окно 5 точек (0.5 м) стартово. Параметр в
config.yaml. Используется для сегментации, классификации формы
и литопрофиля. Сглаживание исходной SP для нормализации не
применяется — только для aSP.

Нормализация — перцентили 2/98, для каждой скважины отдельно,
внутри рабочего интервала. Близко к min/max (как в Petrel), но
устойчиво к одиночным выбросам (см. ADR-007).

Фациальные модели (барьерные острова, дельты, устьевые бары)
пока не включаем. Сначала базовые типы формы.

Положение «в разрезе» (региональное, относительно реперов)
не считаем. Нужны региональные реперы.

Учёт GK. Сейчас для классификации используем только aSP.
GK_norm считаем и сохраняем, но в правила не включаем.

Микроинтервалы < 1 м. Не участвуют в типизации, но
присоединяются к соседям на сегментации.

MD → TVDSS: линейная интерполяция по .dev. Погрешность
при шаге 20 м — менее 1 см, что на порядок ниже шага каротажа.
