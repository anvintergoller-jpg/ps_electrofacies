# Признаки для типизации пластов

**Версия:** 0.2 (согласовано)
**Дата:** 2026-09-25
**Статус:** утверждено, используется для разработки

## 1. Назначение документа

Этот документ фиксирует **какие признаки** мы считаем для каждого пласта
и каждого коллекторного интервала, и что каждый признак означает.

Код (`src/domain/features.py`) реализует то, что написано здесь.
Если что-то меняется в методике — сначала правится этот документ,
потом код.

## 2. Ключевые понятия

### 2.1. Пласт-контейнер (container)

Интервал между двумя соседними кровлями (по отбивкам).

Пример для скважины 227_2263:
  БС9_TOP_S      = 2615.15 м MD
  БС10-1_TOP_S   = 2653.20 м MD  ← конец пласта БС9 и начало пласта БС10-1

Пласт-контейнер БС9 = [2615.15, 2653.20] м MD, мощность 38.05 м.
Последний пласт БС12 — до конца данных в .dev (или в LAS).

Пласты-контейнеры задаются **геологом** через отбивки. Мы не оспариваем
их границы и не сдвигаем. Но можем подсветить статистические аномалии
(раздувы/сужения относительно выборки других скважин).

**Единицы мощности.** По умолчанию мощность пласта и любого интервала
считается **по абсолютным отметкам (TVDSS)**. Это инвариант к углу
наклона ствола и позволяет корректно сопоставлять пласты между скважинами.

Обозначения:
- `thickness_tvdss` — **главная метрика мощности**, м
- `thickness_md` — справочная, для контроля и отображения в LAS-контексте

Для скважины 227_2263 на глубинах 2600–2800 м разница между MD и
TVDSS-мощностью достигает 1–2%. В более глубоких и наклонных интервалах
других скважин может достигать 10–20%, поэтому правило критично.

### 2.2. Коллекторный интервал (reservoir interval)

Непрерывный интервал внутри пласта-контейнера, где кривая SP_norm
указывает на породы-коллекторы: **SP_norm < 0.6**.

Один пласт может содержать:
- 0 коллекторных интервалов (глинистый пласт),
- 1 коллекторный интервал (одиночный песчаник),
- 2 и более коллекторных интервалов (переслаивание).

### 2.3. Микроинтервал (micro interval)

Коллекторный интервал мощностью **< 1 м**.
В расчёт NTG и в типизацию **не идёт**, но учитывается отдельным счётчиком.

### 2.4. αПС (alpha-PS, приведённый ПС)

Классическая безразмерная величина:
    αПС = 1 − SP_norm

Шкала αПС (0 = глина, 1 = чистый песчаник).
Применяемая классификация — по Муромцеву В.С., 5 равных отрезков:

| αПС        | Литология                        | SP_norm       |
|------------|----------------------------------|---------------|
| 0.0 – 0.2  | глина                            | 0.8 – 1.0     |
| 0.2 – 0.4  | алевролит глинистый              | 0.6 – 0.8     |
| 0.4 – 0.6  | алевролиты и песчаники           | 0.4 – 0.6     |
| 0.6 – 0.8  | песчаник среднезернистый         | 0.2 – 0.4     |
| 0.8 – 1.0  | песчаник крупнозернистый         | 0.0 – 0.2     |

Граница «коллектор / не коллектор»: **αПС = 0.6** (то есть SP_norm = 0.4).

Оговорка: термины «среднезернистый», «крупнозернистый» — условные,
это интерпретация по форме кривой, а не прямое измерение зерна.

## 3. Уровни признаков

Признаки делим на три уровня:

- **A. Пласт-контейнер** — одна строка на пласт.
- **B. Коллекторный интервал** — одна строка на интервал (может быть
  несколько на один контейнер).
- **C. Связка** — сводная характеристика пласта: NTG, доминирующий тип
  и т.д. (заполняется на шаге F, пока не считаем).

## 4. Признаки пласта-контейнера (уровень A)

| Признак                  | Тип   | Что означает                                                |
|--------------------------|-------|-------------------------------------------------------------|
| `layer_name`             | str   | Имя пласта (по отбивке кровли)                              |
| `top_md`, `bottom_md`    | float | Кровля / подошва по стволу, м                               |
| `top_tvdss`              | float | Кровля в абсолютных отметках, м                             |
| `bottom_tvdss`           | float | Подошва в абсолютных отметках, м                            |
| **`thickness_tvdss`** ⭐  | float | **Мощность по абсолютным отметкам, м** — главная метрика    |
| `thickness_md`           | float | Мощность по стволу, м — справочно                           |
| `n_points`               | int   | Всего точек каротажа в пласте                               |
| `n_sp_valid`             | int   | Точек с валидным SP_norm                                    |
| `sp_coverage`            | float | Доля валидных точек, 0..1                                   |

**Смысл `thickness_tvdss`:** для наклонных скважин мощность по стволу
и по абсолютным отметкам сильно различаются. В вашей скважине смещение
MD−TVDSS достигает 138 м, поэтому это критично для корректного
сопоставления пластов между скважинами.

## 5. Признаки коллекторного интервала (уровень B)

Считаем для **каждого** коллекторного интервала (SP_norm < 0.4 после
сглаживания и фильтрации). Интервалы длиной < 1 м — не считаем.

### 5.1. Положение в скважине

| Признак                | Тип   | Что означает                                 |
|------------------------|-------|----------------------------------------------|
| `layer_name`           | str   | Пласт-контейнер, к которому относится        |
| `interval_index`       | int   | Номер интервала внутри пласта (1, 2, 3...)   |
| `top_md`, `bottom_md`  | float | Кровля / подошва интервала в MD, м           |
| `top_tvdss`            | float | То же в абсолютных отметках, м               |
| `bottom_tvdss`         | float | То же                                        |
| **`thickness_tvdss`** ⭐ | float | **Мощность интервала по абсолютным отметкам** |
| `thickness_md`         | float | По стволу, справочно                         |

**Расчёт `top_tvdss`, `bottom_tvdss`:** простой линейной интерполяцией
по таблице инклинометрии (`.dev`), функция `md_to_tvd`, применённая
к `top_md` и `bottom_md`. Погрешность при шаге инклинометрии 20 м и
отсутствии резких изломов ствола — менее 1 см.

### 5.2. Статистика кривой

Все значения — по **несглаженной** SP_norm внутри интервала,
кроме `sp_top/mid/bottom`, где используется **сглаженная** кривая.

| Признак            | Тип     | Что означает                              |
|--------------------|---------|-------------------------------------------|
| `mean_sp_norm`     | float   | Среднее SP_norm внутри интервала          |
| `min_sp_norm`      | float   | Минимум (самая «песчаная» точка)          |
| `max_sp_norm`      | float   | Максимум                                  |
| `amplitude`        | float   | `max_sp_norm − min_sp_norm`               |
| `sp_top`           | float   | Медиана в верхних 15% мощности (сглаж.)   |
| `sp_mid`           | float   | Медиана в средней части (сглаж.)          |
| `sp_bottom`        | float   | Медиана в нижних 15% мощности (сглаж.)    |
| `std_sp_norm`      | float   | Стандартное отклонение                    |
| `skewness`         | float   | Асимметрия распределения внутри интервала |
| `kurtosis`         | float   | Эксцесс                                   |

### 5.3. Форма аномалии (предварительно, детали на шаге D)

| Признак               | Тип     | Что означает                                  |
|-----------------------|---------|-----------------------------------------------|
| `anomaly_type`        | str     | bell / funnel / cylinder / symmetric / uncertain |
| `type_confidence`     | float   | 0..1 — уверенность классификации              |
| `slope_top`           | float   | Средний наклон в верхней трети (сглаж.)       |
| `slope_bottom`        | float   | Средний наклон в нижней трети (сглаж.)        |
| `extremum_position`   | float   | 0..1: положение самой песчаной точки внутри интервала |

**Предварительные правила (детали на шаге D):**

  bell:      sp_top − sp_bottom > threshold   (падает сверху вниз)
  funnel:    sp_bottom − sp_top > threshold   (растёт сверху вниз)
  cylinder:  max_sp_norm − min_sp_norm < tolerance   (плато)
  symmetric: разница мала, обе половины похожи
  uncertain: не подходит ни под одно

### 5.4. Положение внутри пласта-контейнера

| Признак                 | Тип     | Что означает                                  |
|-------------------------|---------|-----------------------------------------------|
| `centroid_tvdss`        | float   | Центр масс интервала в абсолютных отметках    |
| `centroid_relative`     | float   | 0..1: положение центроида внутри контейнера   |
| `position_in_container` | str     | top / middle / bottom                         |

**Расчёт `centroid_tvdss`:** среднее TVDSS всех точек интервала.

**Расчёт `centroid_relative`:**
    `centroid_relative = (centroid_tvdss − top_tvdss_container) /
                        (bottom_tvdss_container − top_tvdss_container)`

**Расчёт `position_in_container`:**
- `top`:    `centroid_relative < 0.33`
- `middle`: `0.33 ≤ centroid_relative ≤ 0.67`
- `bottom`: `centroid_relative > 0.67`

**Почему центроид, а не просто медиана.** Центр масс даёт устойчивую
оценку положения интервала. Медиана могла бы «застрять» на границе,
если внутри интервала есть длинный однородный участок.

## 8. Правила отображения и разметки

### 8.1. Ось Y на графике разреза — TVDSS

Это соответствует принятой практике построения корреляционных схем:
все скважины отображаются в единой системе глубин. На одной
корреляционной схеме скважины с разными MD-траекториями выглядят
выровненно по вертикали.

**Что это значит практически:**

- Каждая точка каротажа переводится в `(SP, depth_tvdss)` или
  `(GK, depth_tvdss)`.
- Кровли пластов рисуются горизонтальными линиями на уровне
  `top_tvdss` (интерполированный из MD).
- Фильтрация видимого интервала — по `top_tvdss` верхней кровли
  и `bottom_tvdss` нижней.

### 8.2. Разметка точек пласта — по MD

Точки каротажа приходят с MD-шагом. Попадание в пласт определяется
по MD:
    `(depth_md >= top_md) & (depth_md < bottom_md)`

При этом результат несёт обе координаты: и MD, и TVDSS.
В таблице `dataset.csv` хранятся обе:
- `depth_md` — для сопоставления с LAS и отбивками по исходным данным,
- `depth_tvdss` — для отображения, анализа и сопоставления со скважинами.

## 9. Оговорки и открытые вопросы

1. **Порог SP_norm = 0.6** взят из αПС = 0.6 по Муромцеву.
   Это регионально-зависимая величина. Если для вашего района
   он другой — меняется в config.yaml.

2. **Сглаживание** — окно 5 точек (0.5 м) стартово. Параметр в конфиге.
   Сглаживаем **только для сегментации и классификации формы**.
   Статистику (min/max/амплитуду) считаем по несглаженной кривой.

3. **Фациальные модели** (барьерные острова, дельты, устьевые бары)
   из учебника Ежовой пока не включаем. Сначала базовые типы формы.

4. **Положение «в разрезе»** (региональное, относительно реперов)
   не считаем на этом этапе. Нужны региональные реперы, которых
   в одном файле отбивок нет.

5. **Учёт GK.** Сейчас для классификации используем только SP_norm.
   GK_norm считаем и сохраняем, но в правила не включаем.
   Добавим на этапе мультиметодности.

6. **Микроинтервалы < 1 м.** Не участвуют в типизации, но
   считаются отдельным счётчиком. Могут использоваться как индикатор
   переслаивания.

7. **MD → TVDSS:** простой линейной интерполяцией по таблице
   инклинометрии (`.dev`). Погрешность при шаге инклинометрии 20 м
   и отсутствии резких изломов ствола — менее 1 см, что на порядок
   ниже шага каротажа. Более точное интегрирование (интеграл по
   кривизне) не требуется.

8. **Что делать с интервалами < 1 м.** Присоединяем к соседнему
   коллекторному или неколлекторному интервалу по принципу
   большинства. Если пласт состоит целиком из интервалов < 1 м —
   все они становятся `micro`.
