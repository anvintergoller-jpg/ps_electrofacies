# Проект: типизация пластов по кривой ПС

## Что это

Программа для автоматической типизации пластов по кривой
электрофациального анализа (ПС / SP). Применяется в геологии
нефти и газа для характеристики разреза, корреляции скважин,
построения карт.

## Цель

От единичной скважины — к **типизации пластов** в масштабе
месторождения (сотни скважин). Единица анализа — **пласт-контейнер**
(БС9, БС10-1, …), а не разрез скважины целиком. См. ADR-003.

## Подход

Многоуровневая методика:

1. **Чтение** LAS, .dev, отбивок.
2. **Нормализация** кривых: SP → aSP (αПС, 0 = глина, 1 = песок),
   GK → GK_norm. Перцентили 2/98, для каждой скважины отдельно.
3. **Сегментация** пласта на коллектор / неколлектор по порогу
   aSP = 0.4 (Муромцев).
4. **Классификация формы** каждого коллекторного интервала
   (7 типов: bell, funnel, cylinder, trapezoid-middle, symmetric,
   v-shape, uncertain).
5. **Размер и положение** интервала в родительском пласте.
6. **Сводная типизация** пласта: NTG, доминирующие характеристики,
   метка `container_type`.
7. **Сопоставление** одноимённых пластов между скважинами.
8. **Выгрузка** результатов в Petrel (LAS с FACIES, Points
   with Attributes).

## Данные

- Пилот: 5 скважин (`227_1353`, `227_1354`, `227_2252`, `227_2263`,
  `227_842`), 30 пластов.
- Формат: LAS (SP, GK), .dev (инклинометрия Petrel), общий Excel
  с отбивками.
- Глубины в TVDSS (абсолютные отметки). Наклонные скважины,
  смещение MD − TVDSS до 138 м.

## Технологии

- Python 3.14
- pandas, numpy, matplotlib, lasio, openpyxl, pyyaml
- VS Code, Git, GitHub
- **Без ML** на первом этапе — только правила, объяснимые геологу.
  ML — в перспективе, после накопления 30+ скважин с ручной
  разметкой.

## Принципы

- Сначала методика (документ), потом код.
- Все параметры — в `config/config.yaml`, не в коде.
- Один параметр — одно место в config.
- Правила, объяснимые геологу (без «чёрных ящиков»).
- Максимально подробные комментарии в коде.
