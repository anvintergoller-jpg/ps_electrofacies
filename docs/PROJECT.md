# Проект: типизация пластов по кривой ПС

## Что это

Программа для автоматической типизации пластов по кривой
электрофациального анализа (ПС / SP). Применяется в геологии
нефти и газа для характеристики разреза, корреляции скважин,
построения карт.

## Пилотная скважина

Скважина **227_2263**. Данные из Petrel (LAS, .dev, WellTops Excel).
Глубины ~2364–2599 м в АО (TVDSS). Наклонная скважина,
KB = 113.8 м, смещение MD-TVDSS на забое 138 м.

## Цель

От единственной скважины — к **типизации разреза** в масштабе
месторождения (сотни скважин).

## Подход

Многоуровневая методика:
1. Чтение LAS, .dev, отбивок.
2. Нормализация кривых (уход от единиц измерения).
3. Сегментация пласта на коллектор / неколлектор.
4. Расчёт признаков формы каждого интервала.
5. Классификация формы (bell, funnel, cylinder, трапеции, symmetric).
6. Сводная типизация пласта (потом — разреза).
